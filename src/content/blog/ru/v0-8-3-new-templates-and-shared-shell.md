## Что нового в 0.8.3

**astro-component-kit 0.8.3** добавляет три готовых многостраничных шаблона, четыре компонента для базовых категорий и чистку, которая заметно упрощает поддержку шаблонов с личным кабинетом. Для обновления менять свой код не нужно.

```bash
npm install astro-component-kit@0.8.3
```

## Три новых шаблона

Каждый собран только из собственных компонентов (`reusedComponents: []`), у каждого есть живой предпросмотр, светлая и тёмная темы, переведённые тексты и запись в MCP-сервере.

### Pulse — технологический саммит

Сайт конференции с живым обратным отсчётом, четырьмя треками, расписанием на несколько дней с фильтрами по трекам, поиском и личной программой в браузере, каталогом спикеров, билетами по уровням с проверкой промокодов и интерактивной SVG-схемой площадки.

- Живой предпросмотр: [/preview/tech-event/](/preview/tech-event/)
- Полная статья: [Pulse](/ru/blog/tech-event-template/)

### Veritas — университет

Сайт высшего учебного заведения с поиском направлений, каталогом программ с фильтрами по факультетам, пошаговым поступлением в четыре шага, калькулятором стоимости и стипендий за успеваемость, исследовательскими институтами, жизнью кампуса и регистрацией на день открытых дверей.

- Живой предпросмотр: [/preview/university/](/preview/university/)
- Полная статья: [Veritas](/ru/blog/university-template/)

### Sonora — музыкальный фестиваль

Сайт фестиваля с обратным отсчётом, афишей по дням, расписанием по сценам с личной программой, билетами по уровням с живым итогом и цифровым пропуском. Шаблон готовился под названием «Pulso» и был переименован до выхода, чтобы не совпадать с шаблоном клиники.

- Живой предпросмотр: [/preview/festival/](/preview/festival/)
- Полная статья: [Sonora](/ru/blog/sonora-music-festival-template/)

## Четыре новых базовых компонента

Базовые категории давно не обновлялись, поэтому 0.8.3 закрывает несколько пробелов. Все четыре следуют правилам библиотеки: типизированные пропсы, `class` и нативные атрибуты передаются нужному элементу, варианты, размеры, заметные кольца фокуса и токены, рассчитанные в первую очередь на тёмную тему.

- **Combobox** — выпадающий список с поиском по шаблону ARIA 1.2: ввод для фильтрации, стрелки для перемещения, Enter для выбора, Escape для отмены. Значение передаётся через скрытое поле, поэтому компонент работает в любой обычной форме.
- **GlassCheckbox** — настоящий `<input type="checkbox">` для тёмных интерфейсов с описанием, неопределённым состоянием и вариантами `primary`, `success` и `danger`.
- **DateInput** — поле даты, даты со временем или месяца на нативном выборе даты с подсказкой и состоянием ошибки.
- **SortableTable** — столбцы с сортировкой по клику, объявляемой через `aria-sort`, естественный порядок для текста и чисел и прокручиваемая область с фокусом на узких экранах.

## Общая оболочка личного кабинета

Шаблоны с личным кабинетом повторяли одни и те же экран входа, навигацию, верхнюю панель и заголовок страницы в каждом шаблоне, меняя только тексты и пару типографских деталей. В 0.8.3 всё это вынесено в четыре общих компонента, которые настраиваются через префикс токенов:

- `AccountSignIn`, `AccountNav`, `AccountTopbar` и `AccountHeading`.
- Компоненты Fish, Thea, Wine, Moto, Rest, Perf и Arch теперь тонкие обёртки над ними: 28 файлов и около 5 000 строк меньше.
- Мы сравнили готовый HTML 59 страниц до и после изменения. Разметка совпадает, различаются только случайно сгенерированные идентификаторы.

Если вы копируете эти компоненты в свой проект через CLI, общие файлы копируются вместе с обёрткой.

## Более надёжные релизы

- `npm run audit` теперь принимает `AUDIT_BASE_URL`, `AUDIT_SAMPLE`, `AUDIT_TIMEOUT` и `AUDIT_CONCURRENCY`, пропускает изображения и шрифты и завершается с ошибкой, если страница или предпросмотр не работает.
- Непрерывная интеграция теперь собирает сайт, запускает его и проверяет выборку страниц компонентов в каждом pull request.
