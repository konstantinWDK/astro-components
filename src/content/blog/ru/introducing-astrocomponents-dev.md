## Представляем AstroComponents.dev

**AstroComponents.dev** — это **UI-кит для Astro** с открытым исходным кодом для разработчиков, которые хотят выпускать красивые и доступные интерфейсы, не создавая каждый компонент с нуля.

Проект начинался как личный и сейчас **активно развивается**: каждую неделю в библиотеку добавляются новые компоненты, улучшения и оптимизации.

## Что это такое?

AstroComponents.dev — это большая коллекция из **более чем 200 бесплатных компонентов Astro** в единой тёмной glassmorphism-эстетике. Это ваша основная **библиотека компонентов Astro** для:

- **Лендингов** — hero-секции, сетки возможностей, таблицы тарифов
- **Дашбордов** — карточки, графики, отображение данных, боковые панели
- **Форм** — поля ввода, списки, загрузка файлов, валидация
- **Навигации** — навбары, вкладки, хлебные крошки, выдвижные панели
- **Оверлеев** — модальные окна, тосты, поповеры, баннеры cookie

Каждый компонент работает **без runtime-зависимостей** (чистый Astro + CSS), доступен (WCAG AA) и адаптивен по умолчанию.

## Секции: готовые шаблоны страниц

Одна из главных особенностей этой коллекции **бесплатных компонентов Astro** — категория **«Секции»**. Вместо того чтобы собирать страницу из отдельных деталей, вы получаете **готовые блоки страниц**, которые работают сразу:

- **Hero Gradient** — полноэкранный hero с анимированным градиентным фоном
- **Hero Split** — контент и визуальный макет рядом
- **Hero Glass** — центрированный hero со стеклянным слоем

Каждая секция готова к копированию и полностью адаптивна. Никакой настройки — просто импортируйте и используйте.

## Почему AstroComponents.dev?

| Возможность | Подробности |
|---|---|
| **Ноль зависимостей** | Чистый Astro + CSS. Без React и Tailwind |

## Быстрый старт

```bash
npm install astro-component-kit
```

```astro
---
import { GlassButton } from 'astro-component-kit/buttons';
import { GlassCard } from 'astro-component-kit/cards';
import { GlassNavbar } from 'astro-component-kit/navigation';
---

<GlassNavbar brand="MyApp" brandHref="/">
  <div slot="actions">
    <GlassButton>Начать</GlassButton>
  </div>
</GlassNavbar>
```

Вот и всё. Никакой настройки, конфигурационных файлов и дополнительных шагов сборки сверх того, что уже даёт Astro.
