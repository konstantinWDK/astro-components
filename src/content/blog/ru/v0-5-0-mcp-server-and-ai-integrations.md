## Разработка на Astro с поддержкой ИИ

Вышла версия **astro-component-kit 0.5.0** — масштабное обновление, которое превращает библиотеку в **экосистему для быстрой разработки с помощью искусственного интеллекта**.

Благодаря официальному серверу **Model Context Protocol (MCP)** ваш ИИ-ассистент в **Cursor**, **Claude**, **Codex**, **Lovable** или любой другой MCP-среде получает мгновенный доступ в реальном времени ко всем **340+ компонентам**, **41 SVG-графику** и **3 готовым многостраничным шаблонам**.

---

## 🌟 Что нового в версии 0.5.0

### 1. Официальный удалённый MCP-сервер (SSE)
- **Рабочий адрес:** `https://mcp.astrocomponents.dev/sse`
- Работает на Node.js 22 с поддержкой Server-Sent Events (SSE) и ограничением частоты запросов (120 запр/мин на IP) для высокой надёжности.
- **Автоматическая синхронизация без задержек:** Сервер читает мастер-реестр компонентов. Когда в библиотеку добавляются новые блоки или шаблоны, ваш ИИ сразу может их использовать.

### 2. Установка в 1 команду через CLI
Больше не нужно вручную искать пути к конфигурационным файлам. Выполните одну команду в терминале:

```bash
# Для Cursor (.cursor/mcp.json)
npx astro-component-kit mcp install cursor

# Для Claude Desktop (claude_desktop_config.json)
npx astro-component-kit mcp install claude

# Для OpenAI Codex / ИИ-агентов (.codex/mcp.json)
npx astro-component-kit mcp install codex

# Для проектов Lovable (.lovable/mcp.json)
npx astro-component-kit mcp install lovable

# Для универсального MCP (Windsurf, Cline, Zed и др.)
npx astro-component-kit mcp install mcp
```

### 3. Интерактивный хаб в стиле 21st.dev (`/mcp`)
Ознакомьтесь с новым разделом **[MCP Хаб](/ru/mcp/)** в главном меню сайта:
- Вкладки с командами и прямой конфигурацией для каждого редактора.
- Готовые промпты для e-commerce, графиков, SaaS-панелей и дизайн-токенов.
- Подробное описание всех 8 встроенных инструментов.

### 4. 8 встроенных MCP-инструментов для вашего ИИ
1. `search_components`: Поиск среди 340+ компонентов по ключевым словам, категориям и тегам.
2. `get_component`: Интерфейсы Props на TypeScript, правила доступности и примеры импорта.
3. `get_component_code`: Полный исходный `.astro` код, готовый к вставке в проект.
4. `list_categories`: Список всех 13 категорий с количеством блоков.
5. `list_templates`: Обзор 3 готовых многостраничных шаблонов.
6. `get_template`: Архитектура, страницы и файлы общего состояния шаблонов.
7. `get_design_tokens`: CSS-токены, переменные светлой и тёмной темы, палитра цветов.
8. `get_library_info`: Версия, статистика и краткое руководство по началу работы.
